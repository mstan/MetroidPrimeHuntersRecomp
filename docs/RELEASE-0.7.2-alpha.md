# Metroid Prime Hunters Recomp v0.7.2-alpha

This patch release adds a runner-side in-game settings menu for Prime Controls
mouse sensitivity. Press Escape during gameplay, open Input, and adjust Mouse
sensitivity in 1% steps from 10% through 400%. Changes apply immediately and,
when launched through the recomp-ui launcher, are saved back to the existing
launcher settings file for the next run.

The change is runner-only: it does not require rebuilding ROM banks, repackaging
game data, or resharding live-overlay caches.

Release metadata:

- Windows package version: `0.7.2`
- Linux package version: `0.7.2`
