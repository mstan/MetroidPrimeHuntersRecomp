# MetroidPrimeHuntersRecomp v0.4.7-alpha

Patch release after `v0.4.6-alpha`.

## Changes

- Restores the default lower-screen mouse behavior from `v0.4.5-alpha`: in
  Separate layout, the bottom window remains clickable as normal touchscreen /
  stylus input.
- Keeps keyboard movement available when either Separate-layout screen window is
  focused.
- Moves the `v0.4.6-alpha` cross-window mouse aim capture behavior behind a
  default-off Prime Controls option: `Mouse aim on both windows`.

## Validation

- ndsrecomp `frontend_config_test` and `relative_mouse_touch_test` passed.
- Metroid Prime Hunters launcher `mph-mod-provider-test` passed.
- Windows ZIP package built successfully.
- Linux AppImage package built successfully and passed the AppImage layout test.
