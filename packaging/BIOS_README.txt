Retail BIOS and firmware dumps are optional. The default startup uses the
built-in FreeBIOS and generated firmware. You still need your own supported
USA revision-0 Metroid Prime Hunters ROM; it is not included.

To use dumps from your own Nintendo DS instead, place these files here:

  biosnds9.rom  4,096 bytes    SHA-1 bfaac75f101c135e32e2aaf541de6b1be4c8c62d
  biosnds7.rom  16,384 bytes   SHA-1 24f67bdea115a2c847c8813a262502ee1607b7df
  firmware.bin  262,144 bytes  SHA-1 ae22de59fbf3f35ccfbeacaeba6fa87ac5e7b14b

The runtime verifies every dump and refuses mismatches. These copyrighted
files are not included with the release.
