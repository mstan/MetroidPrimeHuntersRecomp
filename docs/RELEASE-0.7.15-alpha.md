# v0.7.15-alpha

Graphics settings expose Automatic quality and show the effective 3D quality.
Turning Automatic quality Off restores the selected internal resolution and
supersampling immediately. The choice is preserved across current-build state
loads and restarts without replacing other saved preferences.

Fresh profiles retain adaptive Fit to screen; explicit display choices and
native cartridge saves are preserved. Windows retains native OpenGL/HLE and
Linux retains the faithful portable execution profile. Existing fixed 16:9,
depth and touch-window corrections are retained.

Packages include source/build information and component/font notices, including
the full matching TinyCC license beside the bundled compiler. Supply your own
supported ROM; ROMs, BIOS, firmware, saves and captured guest memory are absent.
